# ResumeHelper · 简历工作台

个人使用的 Chrome Manifest V3 扩展。本地管理简历，连接自定义模型 API，从 PDF／图片提取资料，并在招聘网页预览后填写。

## 功能

- 16 个简历分区、240 种字段定义，多份简历、复制、导入导出、完成度统计与未填写筛选。
- 日期支持按月/具体日期选择和结束时间“至今”，自动生成可手改的起止时间；保留旧日期精度。
- 地区支持省市区联动、期望城市最多5项和任意城市；海外和目录缺项可手动填写。专业目录包含本科/专科/硕士/博士共739项，按学历、门类和关键词筛选。每个字段下都有填写说明，包括单位和排名口径。
- 对照官网实际读取的 47 个下拉字段、205 个选项；行业提供 59 项搜索建议，旧版自由输入值继续保留。
- PDF 文字在本地提取；扫描页和图片在本地转为压缩预览，确认后由你配置的视觉模型识别。混合 PDF 保留文字与扫描页，不遗漏扫描页。
- 导入支持 JSON、TXT、Markdown、PDF、PNG、JPEG、WEBP；一次可选多张图片，按选择顺序处理。
- 自定义 OpenAI 兼容 Chat Completions 地址、模型、API Key；图片识别需要服务和模型支持 `image_url` data URL。
- 页面悬浮助手提供整页识别、点击容器选区、资料复制与单项填写；本地明确匹配优先，需要时由用户触发 AI。
- 批量填写先预览，默认保留已有内容，不自动提交申请。

## 安装或迁移

1. 下载仓库，或 `git clone https://github.com/Drchennnn/ResumeHelper.git`。
2. Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选择仓库中的 **`extension`** 目录。
3. 点击扩展 → “管理资料与 API”，填写简历或导入文件。
4. 在“模型设置”保存 Base URL、模型名称及密钥。保存时只申请该 API 域名权限。
5. 在普通招聘网页点击扩展 → “显示页面悬浮助手”，识别、检查预览后确认填写。网页刷新后需要重新启用助手。

已打包 PDF.js，加载扩展不需要 Node、npm、Python、外部 OCR 软件或原产品账号。开发者拉取代码后才需要安装开发依赖。

**从旧目录迁移：** 项目现在位于 `/Users/Link/code/ResumeHelper`。Chrome 的已解压扩展路径仍指向旧目录时，需要改为加载新目录。重新加载前先从旧扩展导出简历 JSON；目录变化可能使扩展 ID 和存储变化，必要时在新版导入 JSON，并重新配置 API。API Key 不随 JSON 导出。

## PDF／图片导入

1. 点击“导入文件”选择 PDF 或图片。文字和图片处理都先在本地完成。
2. 文字 PDF 显示可编辑的提取文本，也可切换“发送页面图片”处理复杂排版；扫描 PDF 自动准备扫描页图片，附上其余页面文字。
3. 预览显示将发送的图片、文本、API 接收方和模型；取消不会发送简历内容。
4. 点击“发送…并 AI 识别”，结果保存为**一份新简历**，原简历保留。识别可能有误，请核对后用于填表。

文件限制：单个 PDF 不超过 10 MiB、8 页；图片最多 8 张、原图各不超过 10 MiB，长边压缩到 1600px；压缩后各不超过 4 MiB、合计不超过 16 MiB；JSON/TXT/MD 不超过 500 KB；模型输入文本最多 10 万字符。加密 PDF 需先解密，DOCX 和 SVG 暂不支持。识别不是离线 OCR：扫描件、图片需要你配置的视觉模型；普通文字 PDF 仍需模型整理成结构化字段。

## 数据与权限

资料和密钥存储在扩展本地；本地读取文件不会把内容发到服务端。只有明确点击 AI 解析／识别／匹配时才请求自定义 API。远程模型会收到你预览的简历资料，密钥通过 HTTPS 或本机 HTTP 发送；不请求原产品后端。API Key 未加密保存，建议使用可撤销的个人密钥。

内容脚本无法直接读取密钥。浮层使用闭合 Shadow DOM，敏感动作检查真实用户事件。PDF.js 和解码器都随扩展打包；保持 `script-src 'self'; object-src 'self'`，禁用 WASM，不加载远程脚本。

## 开发与验证

需要 Node.js 26+（测试直接运行面向现代浏览器的 PDF.js 模块）；打包 ZIP 额外使用 Python 3 标准库。

```sh
npm ci --ignore-scripts
npm run vendor:pdfjs
npm test
npm run check
npm run dev
```

打开终端显示的本机工作台地址；本地预览和正式扩展使用不同存储，**预览只使用虚构资料**。

```sh
npm run dev:mock            # 只在本机开启虚构数据 API，供开发测试
npm run fixtures:documents  # 重新生成虚构 PDF/图片测试样例
npm run package            # 生成 dist/resume-helper-版本号.zip
```

浏览器文档冒烟页为 `/fixtures/document-test.html`，覆盖文字 PDF、扫描 PDF、混合 PDF 与图片预处理。真实模型的识别质量、特殊招聘站自定义控件仍需单独验证。验证范围和浏览器上传限制见 [验证记录](docs/verification.md)。

## 限制与实现来源

工作台已支持地区与专业选择；自动填写招聘网站的复杂联动控件、跨域 iframe、自动新增经历和所有站点适配尚未完成；模型映射重复经历时需要检查预览。社会实践／培训部分字段为常见表单的补充，不声称逐项复刻远端字段。

本项目为独立实现；字段与交互参考“来个简历”客户端和官网可见行为。仓库不包含原扩展代码、私有分析包或真实简历。见 [字段来源](docs/field-coverage.md)、[第三方声明](THIRD_PARTY_NOTICES.md)。

本地地区目录基于2023年数据；专业目录为2026-10-23官网公开分类快照，并非对最新教育部目录的保证。来源与覆盖限制见[地区数据](docs/region-data.md)和[专业数据](docs/major-data.md)。
