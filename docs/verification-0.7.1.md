# 0.7.1 验证记录

日期：2026-10-24。由 0.7.0 递增一个补丁号；没有新增 Chrome 权限或依赖。

## 新实现与边界

- 整页识别通过后台注入有权限的 frame，使用实际 frameId/documentId 缓存；填写前重新核对文档。默认保护已有值，导航后失效，停止后后续 frame 不再接收填写。
- 富文本通过 MAIN 事件桥调用 CKEditor 4/5、TinyMCE、Quill 的公开 API，只传入目标纯文本并核对回读。没有编辑器公开实例时不假装成功。
- 单个自定义菜单精确匹配失败后，可将当前可见候选交给自定义模型理解；只接受已有候选 ID/索引及 >=0.85 的置信度，选后回读。日期与多选保留独立校验，不使用这个单选兜底。
- 连续模式最多 5 轮 / 60 秒，默认只允许当前勾选事实；用户可另外明确允许整份简历。失败签名去重，模型迟到结果不触发后续填写，页面 URL 变化时暂停。
- 新增模块需明确标题/结构和安全添加按钮。新增打开弹窗时停止，不继续猜测。唯一“下一步/继续填写”由独立按钮触发；校验错误、弹窗或多个表单时不继续。没有实现无需用户介入的全站跨页任务恢复。
- 最高/第一学历、最高学位、毕业专业、合并工作/实习分区和受限复合文本按现有事实处理。保留项目/校园隔离、记录身份和日期精度。
- 从原公开配置取得 9 类平台分组参数，添加本地声明式布局适配；ATSX/Moka/飞书完成虚构布局回归，其他布局尚未逐站验收。
- 对照公开 schema 2.0.16 补充证书、家庭、论文、培训字段及导入别名；本地现有 251 个可编辑字段，每个字段保留说明。公开 schema 总字段数包含虚拟字段，与本地可编辑字段数不是同一口径。
