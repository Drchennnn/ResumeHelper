# 本地附件

在工作台或悬浮助手打开“本地附件库”，为当前简历保存简历、成绩单、证书或其他附件。

两种保存方式：

- **预先选择文件**：文件内容保存在扩展 IndexedDB。单文件最多 10 MiB，库中已知大小合计最多 30 MiB。
- **记录绝对路径**：例如 `/Users/name/Documents/resume.pdf`。路径只保存在扩展，填写时通过 Chrome 的 `DOM.setFileInputFiles` 交给目标文件控件，需要已声明的 debugger 权限。文件须仍在该位置；扩展无法提前核验它是否存在或大小是否符合网站限制。

到招聘网页点击扩展图标，展开“本地附件与当前页面”，检查目标网址、附件和文件控件，再点击“选择附件到此页面”。这一步可能触发网站立即上传文件，务必先确认目的地和文件内容。页面跳转或扫描超过十分钟需要重新识别。

扩展会检查文件类型并保护文件控件已有文件；如需更换，请先在网站清空旧附件。当前每次选择一个附件，主框架内真实的 `input[type=file]` 才能识别。跨域 iframe、只提供外部云盘的上传器、控件动态创建前的上传弹窗，需要先手动打开或在网站操作。

结果“已选择”仅表示文件已进入浏览器控件；网站接收、格式校验、病毒扫描等结果应在招聘页面复核。扩展不点击提交申请。附件不会发送给自定义 AI API，也不会随简历 JSON 导出；请自行保留原文件。

本地测试使用 `fixtures/attachment-upload.html`，只记录 input/change 事件和提交按钮点击数，不接收真实文件到服务器。
