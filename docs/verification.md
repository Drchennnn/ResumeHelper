## 0.5.0 通用网页交互（2026-10-24）

- 独立实现通用 DOM 操作：逐字段滚动、pointer/mouse 事件、异步菜单等待、候选精确点击、多选逐项处理、分级路径选择、UD 年月导航、操作后读回。支持部分 ARIA / Ant / Element / Semi / UD 结构，不承诺所有同名组件版本兼容。

### 当前边界

采用 DOM → 浏览器可信输入/点击 → 可选截图视觉规划的顺序，用户确认预览后才填写。浏览器控制可滚动目标字段并点击菜单，但范围限定于当前字段及已确认关联菜单；不执行最终提交、保存、上传、删除或条款接受。跨域 iframe、关闭 Shadow DOM、无法确认归属或无法读回状态的画布控件仍可能需要人工。尚未建立全网站兼容矩阵。
